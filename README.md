# Хранилище сопроводительной информации по проектам

Данное хранилище используется для того, чтобы хранить инфомрацию для внутренних схем и алгоритмов работы проектов.

## Список используемых файлов

### domains.json

Список используемых доменных имен, которые есть на проекте

### launcher.json

Список элементов, которые будут отображаться на уровне лаунчера 

Структура

- server - Сервер, куда пользователя будут подключать
- port - Порт для подключения и проверки
- title - Название сервера в списке

### projects.json

Список проектов, которые участвуют в едином пространстве команды TeapodSoft.

Структура

- title - Наименование в браузере
- description - Описание для браузера и описания на главной странице

### servers.json

Список серверов. Для каждого домена или проекта будет свой список, но хранение будет в едином месте

### socials.json

Список социальных сетей, которые будут отображаться на уровне сайта
